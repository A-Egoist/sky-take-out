# 四周学习计划

默认节奏：工作日每天 60 到 90 分钟，周末做复盘和口述训练。

每天都按同一个顺序走：

1. 讲解：先读当天主题
2. 追问：对照“为什么这样写”
3. 小练习：做 2 到 4 题
4. 复盘：记下 3 个今天最不熟的点

## 第 1 周：Java 语言、对象模型、异常、String、泛型、集合

目标：

- 把 Java 基础语法和常用类重新连起来
- 能读懂仓库里的 `DTO`、`VO`、`Entity` 和集合处理代码

项目锚点：

- `sky-pojo/src/main/java/com/sky/entity`
- `sky-pojo/src/main/java/com/sky/dto`
- `sky-pojo/src/main/java/com/sky/vo`
- `sky-common/src/main/java/com/sky/result`

建议安排：

- 周一：Java 基本类型、包装类、自动装箱拆箱、`String` 与 `StringBuilder`
- 周二：类、对象、封装、构造方法、JavaBean、Lombok
- 周三：异常体系、运行时异常、全局异常处理
- 周四：泛型、`List`、`Set`、`Map`、`ArrayList`、`HashMap`
- 周五：`BeanUtils.copyProperties`、对象拷贝、副作用、代码阅读练习
- 周末：口述一次“对象模型在这个项目里的作用”

本周输出：

- 能说清 `DTO/VO/Entity` 的区别
- 能说清 `ArrayList`、`HashMap` 的基本原理和适用场景
- 能解释为什么统一异常处理比到处写 `try-catch` 更合适

## 第 2 周：OOP、接口、注解、反射、AOP、ThreadLocal、Stream

目标：

- 能理解项目里的公共能力不是“魔法”，而是 Java 基础组合出来的
- 能独立讲明白 `@AutoFill` 和 `BaseContext`

项目锚点：

- `sky-server/src/main/java/com/sky/service`
- `sky-server/src/main/java/com/sky/service/impl`
- `sky-server/src/main/java/com/sky/aspect/AutoFillAspect.java`
- `sky-common/src/main/java/com/sky/context/BaseContext.java`
- `sky-server/src/main/java/com/sky/service/impl/ReportServiceImpl.java`

建议安排：

- 周一：接口与实现类、分层设计、面向接口编程
- 周二：注解基础、反射基础、常用反射 API
- 周三：AOP 核心概念，结合 `AutoFillAspect` 理解切面
- 周四：`ThreadLocal`、请求线程、上下文传递
- 周五：Stream、Lambda、`map/filter/collect/reduce`
- 周末：口述一次“公共字段自动填充是怎么实现的”

本周输出：

- 能解释为什么自动填充适合放到 AOP
- 能说明 `ThreadLocal` 为什么能传递当前用户信息
- 能读懂并手写常见 Stream 转换逻辑

## 第 3 周：Spring Boot、IOC、拦截器、事务、MyBatis、SQL、分页、缓存

目标：

- 把“会用框架”升级成“知道底层在帮我做什么”
- 能讲透下单事务和缓存失效

项目锚点：

- `sky-server/src/main/java/com/sky/config/WebMvcConfiguration.java`
- `sky-server/src/main/java/com/sky/interceptor`
- `sky-server/src/main/java/com/sky/service/impl/DishServiceImpl.java`
- `sky-server/src/main/java/com/sky/service/impl/SetmealServiceImpl.java`
- `sky-server/src/main/java/com/sky/service/impl/OrderServiceImpl.java`
- `sky-server/src/main/resources/mapper/*.xml`

建议安排：

- 周一：Spring IOC、依赖注入、`@Component/@Service/@Autowired`
- 周二：Spring MVC 请求流程、拦截器与参数绑定
- 周三：事务、回滚、传播行为的基础概念
- 周四：MyBatis 映射、动态 SQL、分页插件 PageHelper
- 周五：Redis、Spring Cache、缓存一致性基础
- 周末：口述一次“下单链路为什么必须放事务里”

本周输出：

- 能讲清 JWT 拦截器的职责和执行时机
- 能解释 `@Transactional` 的作用和失效风险
- 能说清菜品缓存的 key 设计、命中逻辑和失效逻辑

## 第 4 周：并发基础、JVM 入门、定时任务、WebSocket、项目表达、模拟面试

目标：

- 把项目里已经用到的并发和运行时知识补到“能回答基础追问”
- 能完成一轮比较顺畅的项目面试

项目锚点：

- `sky-server/src/main/java/com/sky/task/OrderTask.java`
- `sky-server/src/main/java/com/sky/websocket/WebSocketServer.java`
- `sky-server/src/main/java/com/sky/interceptor/JwtTokenAdminInterceptor.java`
- `sky-server/src/main/java/com/sky/interceptor/JwtTokenUserInterceptor.java`

建议安排：

- 周一：线程、进程、线程池、并发风险基础
- 周二：`ThreadLocal` 复盘、共享变量、`HashMap` 并发风险
- 周三：JVM 内存区域、对象创建、垃圾回收入门
- 周四：定时任务、WebSocket、第三方接口的稳定性思考
- 周五：项目表达、常见深挖问题、模拟口述
- 周末：完整模拟一次 15 到 20 分钟项目面试

本周输出：

- 能解释为什么 WebSocket 要考虑线程安全
- 能回答 `ThreadLocal`、`HashMap`、对象生命周期、GC 的基础问题
- 能完整讲清项目亮点、改进点和你的个人贡献

## 每周验收标准

- 1 次项目链路口述
- 1 组基础知识问答
- 1 次错题或薄弱点复盘
- 1 页自己的总结笔记

## 执行时的优先级

- 第一优先级：能说清
- 第二优先级：能写出来
- 第三优先级：能进一步优化

如果某一周感觉内容偏多，不要硬追进度，优先保证“下单链路、AOP 自动填充、JWT + ThreadLocal、事务、缓存”这五块真的熟。
